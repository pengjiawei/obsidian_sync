# 暴露焦虑症

“暴露焦虑症”是[[周濂]]在[[你永远都无法叫醒一个装睡的人]]中，借用政治学语汇对一种特定治理困境进行的犀利描述。它形容政府或相关机构过度关注自身形象与即时回应，以至于在面对民众诉求或社会问题时，采取非理性的高压或收买手段，从而陷入恶性循环的病症。

其表现和逻辑链条为：
1.  **过度回应**：为迅速平息事态、维护形象，对一切暴露的问题做出高调反应。
2.  **手段扭曲**：由于缺乏独立的政治与司法渠道进行制度化的解决，其“回应”手段往往局限于**高压（绝不示弱）** 或**收买（不惜代价）**。
3.  **恶性循环**：这些手段非但不能根本解决问题，反而会激励民众在下一次采取更极端而非更理性的行动，以期获得关注。
4.  **信用透支**：长此以往，表面的“高效”换取的是政府资源和公信力的高度透支，最终成为“空虚的、装模作样的木头人”。

周濂指出，单方面强调官员“责任”而无制度保障，会加剧这一病症。这与Wiki中讨论的[[concepts/非人格化]]（制度理性）缺失、[[queries/如何做一个清醒的现代人]]所要求的理性公民社会条件等议题形成关联，揭示了健康公共生活需要超越这种焦虑式的短期反应。
