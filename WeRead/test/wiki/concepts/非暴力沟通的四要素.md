# 非暴力沟通的四要素

**非暴力沟通的四要素**是[[concepts/非暴力沟通]]模型的核心组成部分，为实践该沟通方式提供了一个具体、可操作的框架。根据阅读笔记，这四个要素依次为：

1.  **观察**：清晰地陈述所观察到的事实，而非进行评判或概括。
2.  **感受**：表达自己的内心感受，区分感受与想法。
3.  **需要**：指出引发上述感受的内在需求或价值观。
4.  **请求**：提出具体、明确、可行的行动请求，而非模糊的要求。

这四个要素构成了一个连贯的表达流程，旨在促使沟通者专注于事实、情感和需求，从而避免由评判、指责或笼统要求所引发的防御与冲突，最终实现基于理解与需求的联结。
