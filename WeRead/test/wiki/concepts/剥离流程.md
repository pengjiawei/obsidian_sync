# 剥离流程

剥离流程（Peel Process）是由瓦洛丽·伯顿提出的一套四步自我教练工具，旨在帮助人们识别、分析并最终摆脱虚假的内疚感。其核心在于通过提问和自我对话，拆解并重构引发内疚的内心叙事。

## 四个步骤

1.  **P (Pinpoint) - 确定内疚触发点**
    *   **关键问题**：是什么触发了我的内疚感？
    *   **目的**：准确识别并标记引发内疚感的具体情景或想法，为后续步骤提供焦点。

2.  **E (Examine) - 审视你的想法**
    *   **关键问题**：关于这个内疚触发点，我正在对自己说些什么？
    *   **目的**：揭示内心中关于该事件的自动化叙事（通常是自我指责的故事），将其从潜意识带入意识层面进行审视。

3.  **E (Exchange) - 将虚假的想法换成真实的想法**
    *   **关键问题**：针对这种情景，更准确、真实的想法是什么？
    *   **目的**：主动挑战并替换不准确、不公正的负面叙事，构建一个基于真相和自我关怀的新叙事。

4.  **L (List) - 列出你的证据**
    *   **关键问题**：什么样的行动、价值观或证据会支撑关于这一情景的真实想法？
    *   **目的**：通过列举事实证据来巩固新叙事，使其更具说服力和稳定性，从而完成对虚假内疚的“剥离”。

## 应用要点

*   这个过程并非总是线性的，可能需要反复循环。
*   在“审视想法”和“替换想法”阶段，常需要用到[[concepts/推回]]技巧来质疑“应该”式思维。
*   流程的终点是能够区分内疚是真实（需负责弥补）还是虚假（需有意识放下），从而解放自我，做出更理智的回应。
