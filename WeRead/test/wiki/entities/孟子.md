# 孟子

孟子（约公元前372年-公元前289年），名轲，战国时期儒家学派的重要代表。他继承和发展了孔子的思想，被后世尊为“亚圣”。在冯友兰的分类中，孟子是**儒家的理想主义流派**。

## 核心哲学主张

1.  **性善论**：孟子主张人性本善。他认为人生来就具有“四端”——恻隐之心（仁之端）、羞恶之心（义之端）、辞让之心（礼之端）、是非之心（智之端）。道德是内在的，人需要通过修养扩充这些善端。
2.  **仁政与民本思想**：将“仁”从个人道德推广到政治领域，主张“仁政”和“王道”。提出“民为贵，社稷次之，君为轻”的民本思想，并认为人民有反抗暴政的“革命权利”。
3.  **浩然之气**：提出培养“浩然之气”，这是一种集义所生、充塞于天地之间的道德勇气和精神力量。
4.  **内在道德形而上学**：孟子认为，人间的道德原则是宇宙间的形而上学原理的体现，人性是这些原理的实证。因此，尽心、知性、知天是相通的。

## 与荀子的分野

孟子与主张“性恶”的荀子构成了儒家内部最重要的哲学辩论。孟子强调道德的内在自发性，荀子则强调外在礼义教化和社会规范的重要性。这一辩论深刻影响了后世儒家思想的发展路径。
