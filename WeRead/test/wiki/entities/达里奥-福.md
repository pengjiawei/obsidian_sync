# 达里奥·福

达里奥·福是意大利剧作家、诺贝尔文学奖得主，被誉为“为平民与被压迫者创作的游吟诗人”。他的创作紧密联系社会现实，具有强烈的政治批判色彩。

他的代表作 [[一个无政府主义者的意外死亡]] 充分体现了其 **艺术介入社会** 的创作理念。该剧基于1969年的真实司法事件，通过精细调查和艺术加工，迅速创作完成，旨在揭露和批判社会政治现实中的权力滥用与司法不公。

达里奥·福的艺术风格融合了 **喜剧作为批判工具** 的方法，通过荒诞的情节和即兴表演，解构权威、讽刺社会弊病，对后世许多戏剧创作者（如孟京辉）产生了深远影响。
