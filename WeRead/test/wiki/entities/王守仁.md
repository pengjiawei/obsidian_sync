# 王守仁

王守仁（1472年-1529年），字伯安，号阳明，明代伟大的思想家、军事家、教育家。他是宋明理学中“**陆王心学**”一派的集大成者，其“心学”思想构成了对朱熹“理学”的系统性反驳。

## 核心心学体系

1.  **心即理**：反对朱熹“性即理”和“理在气先”的观点，主张“心外无理”、“心外无物”。认为宇宙的法则（“理”）就在每个人的心中，无需外求。
2.  **知行合一**：强调知与行的统一，认为真知必然包含行动，行动本身即是知识的完成与体现。反对将知与行分为先后两截。
3.  **致良知**：这是王阳明思想的核心命题。“良知”是人先天具有的、能知善知非的道德本心。所谓“致良知”，就是在事事物物上遵循良知的指引去行动，通过实践来扩充和实现良知，最终达到“明明德”的圣人境界。
4.  **四句教**：概括其学说为“无善无恶心之体，有善有恶意之动，知善知恶是良知，为善去恶是格物”。

## 与朱熹的根本分歧

王阳明与朱熹的辩论，核心在于“理”的归属问题：朱熹认为“理”是客观外在的，需要通过“格物”去穷尽；王阳明则认为“理”就内在于人心，修养的关键是向内发明“良知”。这代表了儒学从外向求理到内向求心的根本转向。
