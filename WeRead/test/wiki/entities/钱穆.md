# 钱穆

钱穆（1895-1990），中国现代著名历史学家、思想家、教育家，新儒家学派的代表人物之一。他一生致力于弘扬中国传统历史文化，对中国古代政治制度、思想史和社会结构有深入研究。

## 主要贡献与观点

1.  **中国历代政治制度研究**：在《[[中国历代政治得失]]》等著作中，他系统梳理了汉、唐、宋、明、清等主要朝代的政治制度，强调其因革演变与内在精神。
2.  **“部族政权”理论**：提出了理解元、清等朝代性质的关键概念——[[部族政权]]，认为其政治本质是基于特定族群私利的独裁，区别于由读书人辅助的、相对“公”的政府形态。
3.  **文化本位史观**：主张从中国历史内部理解其发展脉络，反对以西方或现代的某些概念（如“封建社会”）简单套用于中国历史。
4.  **对“士人政治”的推崇**：高度评价通过科举制度选拔读书人参与政权运作的模式，认为这是中国历史上相对公正且富有弹性的政治设计。

钱穆的史学研究具有强烈的现实关怀和批判精神，旨在从历史中探求民族文化的未来出路。
