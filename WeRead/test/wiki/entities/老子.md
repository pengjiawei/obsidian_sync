# 老子

老子是中国古代伟大的哲学家，道家学派的创始人，其思想核心集中体现在《道德经》（又称《老子》）中。在冯友兰的叙述中，老子代表了**道家的第二阶段**。

## 核心哲学思想

1.  **“道”作为本源与规律**：“道”是宇宙万物的本源和普遍规律。它“无名”，超越具体形象（“无形无象”），却又内在于万物之中（“在万物之中，道就是‘德’”）。
2.  **“无为”的政治与人生哲学**：主张顺应自然规律，不妄加干预（“无为”），从而达到“无为而无不为”的效果。这既是统治者的治国方略（使百姓自化），也是个人应处世态度。
3.  **辩证思维与反向运动**：提出“反者道之动”，事物会向其对立面转化。因此，应持守柔弱、谦下、寡欲、弃智（减少知识欲望带来的纷扰），以保全生命与本性。
4.  **批判人为与回归自然**：严格区分自然与人为，谴责过度的人为造作（如礼法、智巧），认为它们背离了“道”的质朴状态。

## 历史地位

老子的思想与儒家构成了中国哲学中“有为”与“无为”、“入世”与“出世”两大主流的张力。其思想在魏晋玄学中得到复兴，并深刻影响了后世道教、中国化佛教以及文人的精神世界。
