# 弗洛姆 (Erich Fromm)

德裔美国心理学家、社会哲学家。在《[[九诗心：暗夜里的文学启明]]》中，作者引用了他的著作《[[爱的艺术]]》中的观点。

书中用其关于“专心”和“有意义的谈话”的论述，来解读陶渊明的诗歌，强调真诚、基于共同经验的交流（而非抽象空谈）对于建立真实联系和感受存在的重要性。
