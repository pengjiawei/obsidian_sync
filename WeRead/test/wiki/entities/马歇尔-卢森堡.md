# 马歇尔·卢森堡

马歇尔·卢森堡是[[concepts/非暴力沟通]]这一沟通方式的创始人。他是一位著名的心理学家和沟通专家，致力于通过其方法帮助人们实现情意相通，和谐相处。其代表作为《[[entities/非暴力沟通]]》，在该书中系统性地提出了[[concepts/非暴力沟通的四要素]]这一核心实践框架。
