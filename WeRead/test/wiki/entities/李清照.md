# 李清照

宋代女词人，婉约词派代表。在《[[九诗心：暗夜里的文学启明]]》中，作者重点分析了她与丈夫赵明诚共同致力于金石收藏，而后又在战乱中经历失去的过程。

书中将这段经历描述为“残忍的减法”，展现了她在“追忆文学的壮丽”时，对时间流逝（“未来”迟迟未至，“已过”已然过去）的深刻遗憾与叹息，体现了个体生命在宏大宇宙时间中的渺小与哀愁。
