# 墨子

墨子（约公元前470年-公元前391年），名翟，战国初期思想家，墨家学派的创始人。在冯友兰的叙述中，墨子是**孔子的第一位反对者**，其思想代表了与儒家截然不同的平民立场。

## 核心思想与主张

1.  **兼爱**：墨家最核心的伦理主张，反对儒家“爱有差等”的亲亲原则，主张“兼相爱，交相利”，即无差别地平等地爱所有人，并认为这能带来实际的社会利益（“利”）。
2.  **非攻**：反对非正义的侵略战争，认为战争损害双方，是最大的“不义”。
3.  **尚贤、尚同**：主张打破世袭贵族制度，选拔有才能的人治理国家；并建立一个思想统一、听从于“天志”（上天意志）和“天子”的社会秩序。
4.  **功利主义基础**：墨家的伦理和政治主张常以功利主义的计算来论证其合理性，强调行为的后果是否有利于“天下之利”。
5.  **天志与明鬼**：相信“天”有意志，能赏善罚恶，并借助鬼神的观念来增强说服力和约束力。

## 批判与影响

墨家对儒家的礼制、等级观念和宿命论思想进行了猛烈批判。其组织严密、具有侠义精神和苦行色彩。墨家的逻辑学（后期墨家）也取得了很高成就。然而，秦汉之后墨家逐渐衰微，但其“兼爱”、“非攻”的理想仍对中国文化有深远影响。
