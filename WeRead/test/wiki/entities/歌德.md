# 歌德

## 人物简介

约翰·沃尔夫冈·冯·歌德（Johann Wolfgang von Goethe，1749年—1832年），德国著名思想家、作家、科学家，魏玛古典主义的代表人物。他是《浮士德》的作者，被[[叔本华]]视为少数理解其思想的伟人之一。

## 在《人生的智慧》中的角色

在文中，叔本华引用了歌德的一句诗：“我从来不寄希望于任何事情。” 叔本华借此诗阐释其核心观点之一：人只有摆脱了对外部世界的各种期望，回归赤裸的存在本身，才能体会到构成幸福基础的“精神安宁”。因此，歌德在此处作为一个权威的文学和思想引证，用以支持[[内在幸福与独立]]这一哲学主张。
