# 黄晓丹

学者、作家，其著作《[[九诗心：暗夜里的文学启明]]》的作者。

## 视角与方法

她以**女性学者的细腻浪漫**视角，对中国古代诗人进行解读。其方法特点是：
1.  **挖掘不为人知的心灵侧面**：构建丰满立体的诗人形象。
2.  **诗性文笔**：跨越古文障碍，直抵诗人幽微心事，照见共通的生命处境。
3.  **扎实的文献基础**：通过文献校勘和文史互证，再现诗人心灵与现实冲突的历史现场。
4.  **跨学科阐释**：将古典文本与心理学、现代科幻、哲学进行对话。

## 核心关切

她的研究聚焦于古典诗歌对现代人生存困境的回应，特别是探讨诗人在时代动荡中如何转化痛苦、获得从容，其核心观点提炼为“对生命本身的欢庆”。
