# 《皮囊》阅读记录

《皮囊》是作家[[蔡崇达]]于2014年出版的第一部文学作品。这是一部具有小说阅读质感的非虚构散文集。

本书以作者对故乡亲人的情感为出发点，通过14个温情而残酷的故事，冷静地探讨了三大现代人共通命题：**亲人的生老病死、理想与现实的差距、故乡与远方的选择**。它描绘了福建一个渔业小镇的风土人情与时代变迁。

该书自出版后成为现象级畅销书，被誉为“非虚构”写作中独具特色的作品，并获得韩寒、白岩松等多位知名人士推荐。此阅读记录基于微信读书平台，阅读状态为已完成。
