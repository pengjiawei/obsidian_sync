# 维特根斯坦十讲

本书是浙江大学教授楼巍讲解路德维希·维特根斯坦哲学的十堂课程，旨在为读者提供理解维特根斯坦核心思想与命题的清晰导引。全书系统梳理了从早期《逻辑哲学论》到后期《哲学研究》的思想演变。

## 内容概要

-   **第一讲**：介绍维特根斯坦的生平与主要著作。
-   **第二讲至第四讲**：讲解早期思想，核心为“语言图画说”，认为有意义的命题是现实的逻辑图画，并探讨“不可说与显示”。
-   **第五讲至第十讲**：聚焦后期思想，包括反对寻求词语统一本质的“反本质主义”、作为语言与意义核心框架的“语言游戏”、驳斥私人感觉能为词语提供意义的“私人语言论证”、驳斥罗素“归纳原则”的论证，以及关于知识与确定性的讨论。

## 核心贡献

本书以清晰易懂的语言，深入阐释了维特根斯坦哲学中最具影响力的概念，如 [[语言图画说]]、[[反本质主义]]、[[私人语言论证]] 和 [[归纳原则]]，并展示了维特根斯坦思想从前期到后期的重大转变。
