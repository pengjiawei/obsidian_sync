# 《中国历代政治得失》

《中国历代政治得失》是历史学家[[钱穆]]的专题演讲合集，对中国汉、唐、宋、明、清五个主要朝代的政治制度进行了系统性的概观、比照与批判性分析。

## 核心论点

1.  **清代政治是“私心的”部族独裁**：这是本书最具批判性的核心观点。钱穆认为，清代政权由满洲族群作为固定支撑力量，其政治运作的本质是“法术”（为私、无理由的操控）而非“制度”（为公、有规则的遵循）。这种形态在中国历史上仅见于元、清两代，属于典型的[[部族政权]]。

2.  **“制度”与“法术”的区分**：钱穆提出了一个重要的分析框架。以诏书是否需宰相盖章为例，“制度”是公开、有规则、需负责的（公）；“法术”则是皇帝为达私意绕过制度、直接操纵的手段（私）。清代政治被视为以“法术”取代“制度”的典型。

3.  **对“读书人政府”的肯定与对“封建论”的驳斥**：钱穆高度评价了唐宋至明代由科举选拔的[[读书人政府|士人政治]]，认为其相对“公道”，因为读书人不是皇帝的“私势力”。他明确批评将这种模式称为“封建社会”的论断是“胡说”。

4.  **清代系统性的思想压制**：通过详细描述清代学宫“卧碑”上的三条禁令（禁言事、禁结社、禁刊刻），钱穆指出这恰恰是近代西方所争取的“言论自由”、“结社自由”和“出版自由”的反面，具体证明了清代政治的压制本质。

## 分析方法与立场

*   **比较历史学**：全书通过对五个朝代制度的横向对比，揭示其演变与得失。
*   **批判视角**：带有明确的价值立场，推崇“公”的制度，批判基于族群私利的独裁政治。
*   **文化保守主义史观**：强调中国传统文化中相对合理的政治制度层面，反对以简单的“封建社会”标签全盘否定。

## 相关讨论

此书的观点与[[差序格局]]、[[礼治秩序]]等社会结构分析形成互补，共同勾勒中国传统社会的多维图景。钱穆关于“制度”公心与政权私心之间张力的洞察，也与韦伯所讨论的[[非人格化]]理性官僚制存在可比较的理论背景。
