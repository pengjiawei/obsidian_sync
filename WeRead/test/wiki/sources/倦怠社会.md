# 倦怠社会

《倦怠社会》是德国哲学家韩炳哲于2019年出版的哲学著作。该书从“否定性的社会已经消失，取而代之的是充溢着积极性的社会”这一范式转移出发，诊断了当代社会的病理形态。

## 核心论点

韩炳哲认为，现代“功绩社会”已取代了“规训社会”。社会驱动力从否定性禁令（“不允许”）转向积极性指令（“能够”），导致社会病理从歇斯底里症等规训社会典型病症，转向抑郁症、注意力缺乏症、过劳症等“梗阻症”。这些疾病并非源于免疫学意义上的“他者”威胁，而是源于系统内部“过量的肯定性”导致的过载与枯竭。

## 概念框架

*   **功绩社会** 与 **规训社会** 的对比是全书理论基石。
*   书中剖析了 **自我剥削** 的机制，即个体同时作为受害者和施暴者。
*   提出了对抗过度积极性的路径，包括 **深度无聊** 与 **消极的能力**。
*   最终构想了一种以“倦怠”、无为与共在为核心的 **倦怠社会** 愿景。

## 评价与关联

该书对当代精神疾病的社会根源提供了深刻的哲学诊断，其批判力量具有重要价值。该书探讨的现代性困境与 [[清醒的现代人]] 概念所应对的议题（如祛魅、意义匮乏）高度相关，可相互参照。
