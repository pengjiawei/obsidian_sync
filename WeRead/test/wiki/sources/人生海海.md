# 人生海海

《人生海海》是作家[[麦家]]于2019年出版的小说，由北京十月文艺出版社出版。小说讲述了一个传奇而充满人生况味的故事，围绕一位原本风光无限的“上校”展开。他一生赢了无数场仗，最后却败给一个不足道的秘密。故事在这个秘密的基础上，通过守护欲与窥探欲的对抗推进，展现了日常滋生的残酷与时间带来的仁慈。

## 高亮文本摘录

小说第十三章中的一句台词或叙述，反映了小说世界中的道德观念：

> 什么是道德？损人利己的事可以做，损人不利己的事不能做。

这句话体现了一种功利主义的道德定义，与社会通常宣扬的利他主义标准构成内在张力，可能是小说探讨人性冲突的核心点之一。该概念与[[秘密与窥探]]相关，因为秘密的守护与揭露往往涉及这种道德抉择。
