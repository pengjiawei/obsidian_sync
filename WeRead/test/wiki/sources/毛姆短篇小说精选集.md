# 毛姆短篇小说精选集

这是一部由[[毛姆]]创作的短篇小说精选集，收录了23个短篇作品。该选集的地理背景多样，涵盖英国、法国、意大利、墨西哥以及太平洋岛国等地。

## 核心主题

根据官方简介，这部作品集的核心在于对人性弱点的精确透视与对人际关系的冷冷剖析。毛姆笔下的世俗男女在各种光怪陆离的场景中出演角色，而迷失的人性最终引发了一连串的悲剧。这体现了短篇小说这一体裁在聚焦特定情境、揭露普遍人性方面的强大能力，是[[短篇小说的人性剖析]]这一概念的典型实践。
